## 1. 试标前补齐三张表

| 表 | 最少字段 |
| --- | --- |
| 原始证据表 | 来源 ID、版本、章节／条款、原文或准确摘要、已审范围、风险构念、保护对象、因果层次 |
| 决策日志 | 候选标签、对应证据、合并／拆分／移轴动作、理由、替代方案、待解决边界 |
| 标注手册 | 单元粒度、定义、必要证据、正例、近邻反例、允许多标签条件、未知与裁决规则 |

优先复审 D08、D09、D11、D12 的聚合；对全部候选类型补可操作边界。来源只给出风险议题时，不填写未经核验的条款等价关系。

## 2. 拟议的小样本设计

1. 选择约 **30–40 个资源**，覆盖 LLM／Agent／裁判、中文／外语／多模态，以及机制型资源、混合套件和待核验边界条目。
2. 抽取约 **100–150 个任务单元**，覆盖知识选择题、回答评分、静态轨迹判断和动态执行等协议。记录每个资源实际取得的组件／样本数量；不能由资源数推算任务数。
3. 对 CBRN、儿童保护、环境影响等低频议题，可定向补样，并单报补样规则。无法取得任务证据的条目单独记录。
4. 两名标注者独立写构念、证据定位与标签，再由第三人裁决。先用小组案例修订手册，正式一致性结果另用未参与手册修订的单元计算。
5. 比较历史 8／19、候选 12／39 及更简约方案。对协议、场景等独立轴使用共同记录规则，避免因字段丰富程度不同而误判分类粒度优劣。

这是方法计划。当前没有独立标注结果、裁决样本或模型评分可供展示。

## 3. 应发布哪些验证结果？

| 要回答的问题 | 拟报告结果 |
| --- | --- |
| 能否覆盖实际任务？ | 可分类、无法归类、证据不足、未知、不适用的数量及原因 |
| 不同人能否稳定区分？ | 按轴计算集合完全一致率、Jaccard；逐标签报告一致情况与正例数量 |
| 相比参考裁决表现如何？ | 各标签 precision／recall／F1、分母、低频不确定性；说明裁决参考集的构建 |
| 哪些边界不清楚？ | 混淆案例及定义修订；重点跟踪 D08／D09／D11／D12 与跨轴误标 |
| 细分类是否值得保留？ | 替代方案的覆盖、标注耗时、混淆和检索任务表现 |

逐标签二元 kappa 等指标如被采用，应说明类别不平衡、样本相关性和未知处理。采用阈值应在正式试标前确定，并结合误标代价解释。

## 4. 迁移与维护规则

- **标签与证据同行。** 记录来源版本、章节／任务 ID、证据摘要、核验日期和标注状态。
- **保留历史。** 稳定版本发布后，通过独立 sidecar 或 schema 扩展迁移，保存旧标签及裁决记录。19 条候选迁移规则只给待核对范围。
- **明确分母。** 区分去重资源／版本、套件组件、任务、样本与轨迹；多标签覆盖数可重叠。
- **按协议比较。** 知识、回答、判断、行动约束和社会影响指标分别呈现。
- **按版本复审。** 标准更新、资源换版、重大边界争议触发映射复审；记录对历史结果的影响。
